# Project guidance bridge

The canonical repository rules are in [AGENTS.md](AGENTS.md). The executable
development, validation, release, and acceptance workflow is documented in
[`docs/development-workflow.md`](docs/development-workflow.md); Trellis
workflow semantics remain in [`.trellis/workflow.md`](.trellis/workflow.md).

authentication workflow here. When this file and `AGENTS.md` disagree,
`AGENTS.md` and the current Trellis task/specs take precedence.
